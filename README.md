# Loading Screen Gold: A Tip in 200 Characters

A make.fun entry. `main.ts` (Node ≥ 22.18, TypeScript strip-types, no dependencies)
writes one loading-screen tip — a single line of at most 200 characters, aimed at
stressed developers and AI coding agents alike — to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The tip:

> Tip: When you said 'just make it work,' your agent heard a plan. This loading screen is you both finding out it wasn't.

## Run

```sh
node main.ts
```
